<h1>My own Starbie</h1>
Starbie is a simple digital pet that reacts to motion, temperature and humidity.<br>
I built this project for hack club half life.<br><br>

<img width="1015" height="742" alt="Snímek obrazovky 2026-10-11 202711" src="https://github.com/user-attachments/assets/9401914b-23b6-4167-8910-01be5ca975e2" />
<h2>My features</h2>
<ul>
  <li>My own pet cat</li>
  <li>Star shaped trail</li>
  <li>Snowflake or sweat drop reaction based on the temperature</li>
</ul>

The PCB was built in KiCad and the firmware was coded in ArduinoIDE. Both were done with the help of a guide from the half life challange.
